# CausalLab_project
My project is called CausalLab, a web-based statistical analysis application designed to help users evaluate experiments and understand the possible causal effects of changes. The main purpose of this project is to support data-driven decision-making by providing statistical methods such as A/B testing, confidence intervals, multiple testing, Bayesian analysis, propensity score matching, difference-in-differences, and synthetic control. I use Python and FastAPI for the backend to process requests and perform statistical calculations, while React is used to develop the frontend user interface. I also use libraries such as NumPy, Pandas, SciPy, Statsmodels, and Scikit-learn for numerical calculations, data processing, and statistical analysis. For example, a company can use an A/B test to compare two versions of a website and evaluate whether one version performs better than the other. This project helps me apply my knowledge of Python, statistics, APIs, and frontend development to a practical data-analysis problem. One important limitation is that reliable conclusions depend on data quality, the experimental design, and the assumptions of the selected statistical method.
